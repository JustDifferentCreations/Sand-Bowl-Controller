# Sand Bowl Controller

The control board for a zen sand bowl. A stepper motor turns a single arm in a circle: one side combs patterns into the sand and the other side smooths it. The board also lights the bowl with RGB LEDs and shows its status on a small OLED.

Designed by [Just Different Creations](https://justdif.com) in Lufkin, Texas. See it on the [PCB Projects](https://justdif.com/pcb-projects/) page.

## Features

- Stepper motor in half-step mode through a motor driver, left or right, 10 speed levels
- Motor driver fault input: the screen shows `FAULT!` and the motor stops until a direction button starts it again
- 9 WS2812 RGB LEDs, 9 colors plus off, 10 brightness levels
- 128x32 SSD1306 OLED showing Running / Paused / FAULT!, direction, color, speed and brightness

## Controls

| Button | While running | While paused |
| --- | --- | --- |
| SW1 | Pause | Run |
| SW2 | Turn left | Previous color |
| SW3 | Turn right | Next color |
| SW4 | Slower | Dimmer |
| SW5 | Faster | Brighter |

## Hardware

- MCU: AVR16DU28
- Display: SSD1306 OLED on a bit-banged I2C bus (PA2 SDA, PA3 SCL)
- LEDs: WS2812 data on PA7
- Stepper outputs: PD0 to PD3 to the motor driver
- Pins, clock and button interrupts are set up with MPLAB Code Configurator (MCC Melody)

## Building and flashing

- MPLAB X IDE with the XC8 compiler (built with v2.45)
- Programmer: PICkit 5
- The `mcc_generated_files` folder is not in this repo. Open the project in MPLAB X, open MCC (it loads `AVR16DU28_Motor_Driver.mc3`), click **Generate**, then build and program the board.
